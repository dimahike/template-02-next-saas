# Project Profile

## Starter purpose
A reusable fullstack-ready Next.js SaaS starter for long-term product development.

## Target project types
- B2B SaaS dashboards and workspaces
- Multi-tenant internal SaaS tools
- Subscription-ready SaaS products (without billing implementation at baseline)

## Expected complexity and growth
- Product stage: long-term
- UI complexity: ui-heavy
- Expected growth: high

## Included
- App Router base with neutral starter page
- Tokenized UI primitives
- API route baseline (`/api/health`)
- Server-only boundary helper
- Validation baseline with Zod
- Mock-data-first domain structure
- Storybook overview story

## Intentionally excluded
- Product-specific screens and user journeys
- Real auth provider integration
- Billing/subscription implementation
- Database integration and migrations
